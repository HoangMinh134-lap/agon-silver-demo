# AGON storefront

A responsive Vietnamese/English sterling silver storefront built with plain HTML, CSS, and JavaScript. The header language switch remembers your choice between page loads.

Open `index.html` for the homepage, `product.html?id=vortex-spine` for a product detail page, or `checkout.html` for the checkout. The homepage lists two products in each category; the detail page switches products using the `id` query parameter. The cart is saved in browser storage, and checkout is a front-end demo with no live order or payment processing. Serve this directory with any static file server to test navigation. The logo is in `assets/agon-mark.png`; product photography and web fonts are loaded from external hosts.
